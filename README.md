# Your Weekend Action Plan

1. Weekday Preparation (Keep doing what you're doing)

Save your 4 monitoring config files to a USB drive, cloud storage, or a private GitHub repo so you can pull them instantly once Ubuntu is installed.

Ensure all your Cisco IOL binaries and FortiGate .qcow2 images are backed up in a safe folder.

# 2. Weekend Execution

Step 1: Install Ubuntu Desktop as your host OS.

Step 2: Download and install VMware Workstation Pro for Linux and import your EVE-NG base virtual machine.

Step 3: Install Docker on Ubuntu Desktop, move your monitoring scripts into /opt/monitoring, and launch the stack natively (docker compose up -d).

Step 4: Install VS Code, launch your EVE-NG lab, point your Cisco/Fortinet nodes' syslog/SNMP to your Ubuntu host IP, and start labbing!

You’re walking away from Windows bloat and moving straight into a lean, professional, industry-standard Linux workstation. Enjoy the build this weekend!
