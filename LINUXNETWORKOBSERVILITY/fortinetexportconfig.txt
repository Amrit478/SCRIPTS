Here is the exact configuration performed on the FortiGate CLI so you can re-apply or save it:

**1. Interface Configuration (`port1`)**

```text
config system interface
    edit port1
        set vdom "root"
        set ip 10.0.0.2 255.255.255.252
        set allowaccess ping https ssh http
        set type physical
    next
end

```

**2. Static Route Configuration (pointing to R2)**

```text
config router static
    edit 1
        set gateway 10.0.0.1
        set device port1
    next
end

```

---

1. **Save Configuration to Flash:** FortiGate CLI.
In FortiOS, changes are applied immediately, but you can explicitly write the configuration to disk:

```text
execute backup config flash "initial_setup"

```

*Verification:* The console will output `Success` confirming the backup file was written.


2. **Display Full Configuration:** FortiGate CLI.
To view and manually copy your complete running configuration text:

```text
show full-configuration

```

*Verification:* Scroll through the output to copy any section directly into a text editor on your host.
